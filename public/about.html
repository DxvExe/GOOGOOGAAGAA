About GOOGOOEXAMPLEGAAGAA

Understanding how Node.js powers a full multi-page web application under the hood.

The Purpose of This Project

GOOGOOEXAMPLEGAAGAA is an educational web project created for Tutedude Assignment 6. It helps build a strong foundation by stepping away from heavy abstractions like Express and Next.js.

By building a web server directly with Node.js standard libraries, we see how the event loop, socket listeners, HTTP request headers, MIME types, and file streams work together to serve web pages to browsers.

  • ✓
    Zero External Dependencies: Built strictly with Node.js built-in modules (http, fs/promises, path, url).
  • ✓
    Standard Status Codes: Returns standard HTTP status codes (200 OK, 302 Found, 404 Not Found, 405 Method Not Allowed, 500 Internal Error).
  • ✓
    Safe Path Handling: Protects local file systems from directory escape exploits through strict path containment checks.
