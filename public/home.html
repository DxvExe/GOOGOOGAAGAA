Native HTTP Module

🧭

URL Routing & Redirects

Handles /home, /about, /contact, cleanly redirects / to /home with HTTP 302, and safely catches invalid URLs.

Non-blocking file reads using fs/promises with async/await for HTML pages, CSS styles, client scripts, and SVG graphics.
